# 개인위치정보 제3자 제공 안내

> **확정안 v1.0 · 시행 보류.** 상대 특정·사전 알림·제공·제공 후 통지 확인 순서를 정하고 로컬 구현에 반영했다. 원격 위치 공유는 운영자 연락처, 법적 사업자 분류/신고 여부, Cloudflare 접근권한 기록 준비와 실제 복구 검증을 마칠 때까지 닫아 둔다.

- 정책 결정 기준일: 2026-10-28
- 시행일: 서비스 일반 API 개방 전에 표시되는 날짜
- 위치정보 운영자와 주소·전화: 실제 운영자 정보 확인 필요
- 위치정보 제공 문의 담당자와 이메일: 실제 지정 필요

## 1. 제공 목적·상대·항목

목적은 수락된 운행의 지정 승차 지점에서 운전자와 승객이 서로를 찾고 만남을 조율하는 것입니다. 이용자는 요청을 보내거나 수락해 상대를 정하고, 위치 공유를 별도 동의합니다. 좌표는 관련 운행의 운전자에게 수락/탑승된 승객의 위치를, 각 승객에게 해당 운전자의 위치를 제공합니다. 다른 승객, 일반 이용자, 학교 및 앱 운영자 화면에는 좌표를 제공하지 않습니다.

제공 항목은 위도·경도, 정확도, 취득·갱신 시각, 역할과 닉네임입니다. 양쪽의 선택 동의, 유효한 계정 자격, 현재 수락된 운행 관계, 차단 여부와 최신 위치를 매 요청 시 확인합니다. 운행이 출발 상태로 바뀌거나 관계가 취소·종료·중단되면 공유를 중단하고 현재 좌표를 지웁니다. 위치로 탑승이나 이동을 자동 확정하지 않습니다.

## 2. 제공 전에 알리고 실제 제공 후 통지

위치 데이터는 다음 순서로 전달합니다.

1. 상대가 새 위치 sequence를 요청하면 서버는 좌표 없이 수신자 닉네임·역할, 요청 시각, 운행/요청 식별자와 목적을 기록합니다.
2. 위치 소유자의 활성 화면에 “누가, 언제, 어떤 목적으로 위치를 요청했는지” 알리고, 이용자가 **위치 요청 안내 확인** 버튼을 누릅니다. 서버가 이 확인 기록을 저장하기 전에는 좌표를 반환하지 않습니다.
3. 안내 확인 후 수신자의 다음 조회에 위치가 실제 반환되면 정확한 제공 시각을 기록합니다.
4. 위치 소유자의 화면에 제공받은 자·실제 제공 시각·목적을 다시 표시하고, 이용자가 **위치 제공 안내 확인** 버튼을 누르면 그 시각을 저장합니다.

위치 화면은 5초 간격으로 갱신합니다. 위치 소유자의 화면이 활성 상태이고 통신이 되는 경우에만 새 위치 제공 요청을 처리하며, 화면이 없거나 이용자가 사전 안내 확인 버튼을 누르지 않으면 상대에게 좌표를 반환하지 않습니다. 제공 후 통지도 이용자가 확인 버튼을 눌렀을 때 확인 시각을 저장합니다. 닫힌 앱 푸시 알림은 제공하지 않습니다. 통신 실패 중 새 위치가 생기면 해당 위치가 만료되거나 새 위치로 교체되기 전까지 제공되지 않을 수 있습니다.

한 위치 sequence는 수신자별 한 번만 좌표 응답으로 보냅니다. 같은 sequence의 반복 조회는 다시 제공하지 않으며, 새 sequence마다 별도 요청·제공 기록을 남깁니다. 현재 화면은 최근 20건을 표시합니다. 전체 내역 열람은 공개된 문의처로 요청할 수 있어야 합니다.

## 3. 제공기간·보관·백업

수신자는 서버 수신 시각 기준 60초 이내의 최신 위치만 받습니다. 최신 위치 한 건은 새 업로드로 교체되며, 위치 제공 통지 확인자료는 좌표 없이 최대 6개월 보관합니다. 위치 소유자가 위치 관련 동의를 철회하거나 탈퇴하면 그 사람의 위치 제공·통지 확인자료와 위치 소유자 접근기록을 즉시 온라인 DB에서 삭제합니다. 수신자의 보안 목적 API 접근기록은 좌표 없이 1년 보관합니다. 위치 시스템 접근권한 부여·변경·말소 이력은 관련 보호조치 기준 적용 시 5년 이상 보관하며, Cloudflare 운영 권한대장은 별도 보호된 외부 기록으로 유지해야 합니다.

staging D1은 Workers Free `production` backend이고 Time Travel 복구 창은 최대 7일입니다. Time Travel은 DB 전체를 덮어쓰는 복구이며 사용자별 삭제를 백업에 즉시 반영하지 않습니다. D1 백업 안의 위치자료 삭제가 적용 법령을 충족하는지는 운영 형태 검토 전까지 미확정이므로 위치 공유는 닫혀 있습니다. 복구 뒤에는 일반 API를 닫은 채 탈퇴·철회 이력을 재적용합니다. 상세 순서는 [운영 복구 절차](../operations/data-retention-and-restore.md)에 따릅니다.

## 4. 거부·철회·문의

위치 제공 동의는 위치 수집 동의와 별도로 선택하며 언제든 철회할 수 있습니다. 거부·철회하면 이후 제공을 중단하고 본인의 최신 위치, 본인 위치에 관한 제공·통지 확인자료와 owner 접근기록을 온라인 D1에서 즉시 지웁니다. D1 백업 사본의 삭제는 별도 검토가 끝날 때까지 확정되지 않았습니다. 위치를 제공하지 않아도 가능한 범위에서 고정 승차 지점과 탑승 코드를 이용할 수 있습니다.

개인위치정보 제공 내역 열람·고지·정정 및 철회 요청은 운영자가 실제 지정해 공개하는 이메일/전화로 접수합니다. 실명/상호, 주소, 담당자와 연락처는 실제 운영자 확인 전에는 게시할 수 없습니다.

## 근거

위치정보법 적용 시 이용자가 지정한 제3자에게 개인위치정보를 제공할 때마다 제공받는 자·제공일시·목적을 즉시 통지해야 하며, 동의를 철회하면 해당 위치정보 및 확인자료를 지체 없이 파기해야 합니다. 시행령은 통지 단말기 기준도 정합니다. 현재 구현은 좌표 전 이용자 확인을 요구하고 제공 후에는 실제 시각·상대·목적을 표시해 별도 확인을 받습니다. 푸시나 화면 외 통지는 하지 않습니다. 통지의 적시성, 백업 파기, 사업자 분류·신고/등록 여부는 법률 검토와 실기기 복구 검증 전 미확정입니다.
