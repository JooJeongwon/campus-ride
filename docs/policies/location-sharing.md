# 위치 공유 처리 검토 메모

> **설계 검토용 초안 · 미게시·미효력 · 실제 제3자 제공 동의에 사용하지 않음.** 2026-10-31 제품 변경으로 실시간 좌표 공유 기능을 비활성화했다. 법률상 의무의 충족이나 면제를 뜻하지 않는다.

## 현재 제품 동작

- 동승 상대에게 이용자 단말의 좌표, 정확도, 위치 갱신 시각을 보내지 않는다.
- 운전자와 탑승자는 등록된 노선의 고정 승차 지점을 선택하고 그곳에서 직접 만난다. 노선 선택과 요청은 앱 데이터에 연결되므로 이용자가 의도한 만남 장소를 나타낼 수 있다.
- 앱은 이용자의 승차 지점 도착 여부를 추적하거나 상대에게 알려주지 않는다. 현장 탑승은 6자리 탑승 코드로 서로 확인한다.
- 클라이언트의 위치 공유 화면과 polling, 지도 SDK 로딩을 제거했고 Worker의 위치 라우트를 등록하지 않았다. 새 위치 동의 부여 요청은 거절된다.
- 이전 구현의 DB 행이나 백업 사본은 남아 있을 수 있다. 현재 사용자 화면에서 과거 좌표/제공 내역을 조회할 수 없으며, 잔여 데이터 처리·파기 계획은 별도 검토 대상이다.

## 법률·운영 검토 미완료

실시간 좌표 제공을 중단하면 해당 실시간 제공 흐름은 발생하지 않는다. 다만 고정 지점 선택 정보가 특정 이용자의 위치정보 또는 개인정보에 해당하는지, 그 처리와 제3자 제공에 어떤 법적 근거·고지가 필요한지는 실제 운영 형태에 따라 확인해야 한다. 위치정보법 적용 여부, 사업자 분류·신고, 학교의 공식 운영 승인·위임, 처리 위탁·국외 이전, 온라인 DB와 복구 사본의 보유·삭제는 확정되지 않았다.

현행 위치정보법 제24조는 위치정보 관련 동의 철회 및 일시중지 요구 등 정보주체 권리를 규정한다. 현재 기능 변경만으로 과거 데이터의 파기 의무가 이행되거나 백업 사본이 삭제되는 것은 아니다. 잔여 데이터와 복구 절차를 검토하고 법적 의무를 확인하기 전까지 이 문서는 공개 정책이나 실사용 동의로 쓰지 않는다.
