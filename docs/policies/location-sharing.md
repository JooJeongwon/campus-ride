## 1. 제공 목적·상대·항목

목적은 수락된 운행의 지정 승차 지점에서 운전자와 승객이 서로를 찾고 만남을 조율하는 것입니다. 좌표는 관련 운행의 운전자에게 수락/탑승된 승객의 위치를, 각 승객에게 해당 운전자의 위치를 제공합니다. 다른 승객과 일반 이용자에게는 제공하지 않습니다. 운영자에게 좌표를 열람하는 운영 화면을 두지 않습니다. 가천대학교가 정식 운영주체로 승인되면 학교 담당자의 역할·범위와 접근권한을 별도 확정해 공개합니다.

제공 항목은 위도·경도, 정확도, 취득·갱신 시각, 역할과 닉네임입니다. 양쪽의 선택 동의, 유효한 계정 자격, 현재 수락된 운행 관계, 차단 여부와 최신 위치를 매 요청 시 확인합니다. 운행이 출발 상태로 바뀌거나 관계가 취소·종료·중단되면 공유를 중단하고 현재 좌표를 지웁니다. 위치로 탑승이나 이동을 자동 확정하지 않습니다.

## 2. 제공 전에 알리고 실제 제공 후 통지

위치 데이터는 다음 순서로 전달해야 합니다. 계정 설정의 일반적인 위치 제공 동의만으로는 특정 상대·목적을 정한 동의를 대신할 수 없습니다. 이 서비스의 설계안은 상대와 만남 조율 목적을 지정한 운행별 공유 세션에 대해 이용자가 적극적으로 허용하도록 하고, 그 세션이 유지되는 동안 실제 제공 때마다 즉시 통지하는 방식입니다.

1. 상대가 새 위치 sequence를 요청하면 서버는 좌표 없이 수신자 닉네임·역할, 요청 시각, 운행/요청 식별자와 목적을 기록합니다.
2. 운행별 위치 공유 세션을 시작하기 전에 수집 단말(또는 이용자가 사전 지정한 알림 단말)에 수신자와 목적, 공유가 유지되는 조건을 표시하고 이용자가 **이 운행에서 이 상대에게 위치 공유**를 적극 선택해야 합니다. 거부하거나 선택하지 않으면 좌표를 반환하지 않습니다. 일반 설정의 위치 제공 동의와 운행별 세션 동의를 구분해 기록합니다.
3. 승인된 세션 안에서 수신자에게 위치가 실제 반환될 때마다 정확한 제공 시각·수신자·목적·취득경로·제공방법을 자동 기록합니다.
4. 각 제공 직후 제공받는 자·제공일시·목적을 위치를 수집한 동일 단말 또는 이용자가 사전 지정한 단말에 통지하고 통지 결과를 기록합니다. 이 문서는 즉시 통지를 기준으로 하며 모아서 통보하는 방식은 제공하지 않습니다.

위치 화면은 현재 5초 간격으로 갱신합니다. `npm run test:integration -- tests/integration/locations.test.ts` 실행 결과 1개 Workers/D1 통합 테스트가 통과해, 좌표를 보여주기 전 사전 안내 확인과 제공 뒤 별도 안내 확인이 순서대로 기록되는 점, 권한/관계/TTL 제한이 동작하는 점을 확인했습니다. 이 테스트는 현행 API·DB 동작만 검증합니다. 별도 운행별 공유 세션 동의 저장소와 동의·거부 기능은 없고, 계정 heartbeat polling은 실제 GPS 수집 단말 또는 사전 지정한 통지 단말을 식별하지 못하며 각 제공 직후의 통지를 보장하지 않습니다. 별도 일시중지 기능도 없습니다. 따라서 이 검증은 법정 동의·즉시 통지의 충족을 입증하지 않습니다. 세션 동의, 단말 연결, 통지 실패 시 제공 차단, 법정 확인자료 필드, 백업 파기와 실기기 검증이 끝나기 전 위치 공유를 열지 않습니다.

한 위치 sequence는 수신자별 한 번만 좌표 응답으로 보냅니다. 같은 sequence의 반복 조회는 다시 제공하지 않으며, 새 sequence마다 별도 요청·제공 기록을 남깁니다. 현재 화면은 최근 20건을 표시합니다. 전체 내역 열람은 공개된 문의처로 요청할 수 있어야 합니다.

지도 표시에는 NAVER Cloud Platform Web Dynamic Map을 사용합니다. SDK와 지도 타일 요청 과정에서 브라우저의 접속 IP, Client ID, 출처와 타일/표시 영역이 제공자에게 전달될 수 있습니다. NCP 개발 문서는 Maps 약관이 데이터 보관·사용 및 개인정보 위탁을 다룬다고 안내하지만, 실제 동의된 약관 버전의 국가·보유기간·하위 처리자는 확인하지 못했습니다. NCP의 글로벌 리전 안내를 Maps API 국가로 대입하지 않으며 해당 확인과 고지를 마칠 때까지 이 안내를 시행하지 않고 원격 일반 API도 닫습니다.

## 3. 제공기간·보관·백업

수신자는 서버 수신 시각 기준 60초 이내의 최신 위치만 받습니다. 최신 위치 한 건은 새 업로드로 교체됩니다. 위치정보법 적용 시 확인자료를 자동 기록하고 원칙적으로 최소 6개월 보관하며, 관련 동의 철회 때는 철회 범위의 위치 및 확인자료를 지체 없이 파기합니다. 수집사실 확인자료에는 수집요청인·수집일시·수집방법이, 이용·제공사실 확인자료에는 제공받는 자·취득경로·이용·제공일시·방법이 포함됩니다(확인자료에 좌표 자체는 포함하지 않음). 현재 schema는 소유자·수신자·운행/요청·sequence·목적·일부 시각을 저장하지만 수집방법·취득경로·제공방법까지 자동 기록하는지 검증되지 않았습니다. 수신자의 보안 목적 API 접근기록은 좌표 없이 1년 보관합니다. 위치 시스템 접근권한 부여·변경·말소 이력은 적용 기준에 따라 최소 5년 보관합니다. Cloudflare 운영 권한대장은 별도 보호된 외부 기록으로 유지해야 하나 현재 구축되지 않았습니다.

staging D1은 직전 기록상 Workers Free `production` backend/APAC이고 Time Travel 복구 창은 최대 7일입니다. 한국 jurisdiction 옵션은 제공되지 않습니다. APAC 위치 힌트는 국가를 보장하지 않고 기존 DB는 jurisdiction을 나중에 붙일 수 없습니다. 이번 읽기 전용 조회는 Cloudflare API 인증 오류로 실패했습니다. Time Travel은 DB 전체를 덮어쓰는 복구이며 사용자별 삭제를 백업에 즉시 반영하지 않습니다. 외부 삭제·철회 대조부는 복원 후 재노출 방지를 돕지만 백업 사본 자체를 파기하지 않습니다. D1 백업 안 위치자료의 파기 적합성을 해결하고 복구 훈련을 마치기 전 위치 공유는 닫혀 있습니다. 상세 순서는 [운영 복구 절차](../operations/data-retention-and-restore.md)에 따릅니다.
