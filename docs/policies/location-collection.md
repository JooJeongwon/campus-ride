# 개인위치정보 수집·이용 안내

> **확정안 v1.0 · 시행 보류.** 수집 범위와 보유기간은 이 기준으로 구현한다. 실제 시행 전 운영자/문의처와 위치기반서비스 관련 신고·등록/예외 해당 여부, 위탁·국외이전 고지를 확정해야 한다. 현재 원격 일반 API는 닫혀 있다.

- 정책 결정 기준일: 2026-10-28
- 시행일: 서비스 일반 API 개방 전에 표시되는 날짜
- 위치정보 운영자·주소·전화: 실제 운영자 값 확인 필요
- 위치정보 담당자와 공개 이메일: 실제 담당자 값 확인 필요

## 1. 목적과 수집 방법

가천대학교 글로벌캠퍼스 이용자 간 수락된 운행에서, 지정 승차 지점에서 서로 만날 수 있도록 최신 위치를 표시합니다. 위치는 참고 정보이며 실제 탑승·출발·도착 판정이나 긴급 구조에 사용하지 않습니다.

이용자가 위치 공유 화면에서 시작 버튼을 누르고, 별도의 위치 수집 동의와 브라우저 위치 권한을 허용할 때만 브라우저 Geolocation 정보를 전송합니다. 앱 화면이 숨겨지면 브라우저 위치 추적을 멈춥니다. 백그라운드 추적, 항상 정확한 위치, 통신 성공을 보장하지 않습니다.

## 2. 수집 항목과 이용 범위

- 브라우저가 제공한 위도·경도와 정확도(미터)
- 위치 취득 시각과 서버 수신 시각
- 운행·탑승 요청 식별자, 갱신 sequence

이용자별 최신 위치 한 건만 저장하고 새 위치가 오면 덮어씁니다. 위치는 수락된 관계에서 상대를 찾는 용도로만 사용하고, 위치 이력을 만들거나 지도 경로를 추적하지 않습니다. 브라우저 권한을 거부하거나 동의를 철회하면 새 위치를 받지 않습니다.

## 3. 보유기간과 삭제

위치 좌표는 서버 수신 후 60초 동안만 API 응답 대상입니다. 60초가 지나면 API가 좌표를 반환하지 않습니다. 출발·취소·종료·중단, 관련 관계 해제, 위치 동의 철회 또는 탈퇴 때 최신 위치 행을 제거합니다. 위치 동의 철회·탈퇴 시에는 해당 사람의 위치에 관한 제공·통지 확인자료와 위치 소유자 접근기록도 온라인 DB에서 즉시 삭제합니다. 만료 행은 5분마다 실행되는 정리 작업으로 물리 삭제합니다. 정리 작업은 한 번에 제한된 행을 지우므로 오류나 적체가 있으면 물리 삭제가 늦어질 수 있습니다.

삭제된 온라인 행과 별도로 staging D1 Time Travel에는 최대 7일의 복구 창이 있습니다. 이 기간 안에는 과거 시점의 좌표·제공자료가 복구될 수 있습니다. D1 백업에서 이 자료를 사용자별로 즉시 지울 수 있는지와 위치정보법상 허용되는지는 확인되지 않았습니다. 이 문제와 D1 밖의 삭제·철회 대조부를 해결하고 복구 훈련을 마치기 전 위치 서비스와 일반 API를 열지 않습니다. 복구가 발생하면 공유 API를 닫아 둔 상태로 탈퇴·철회를 재적용해야 합니다. 이 절차는 [운영 복구 절차](../operations/data-retention-and-restore.md)에 따릅니다.

## 4. 권리 행사와 대체 이용

위치 수집·제공 동의를 각각 거부하거나 언제든 철회할 수 있습니다. 위치 관련 동의 철회 시 새 업로드와 상대 조회를 차단하고 최신 좌표, 해당 사용자의 위치 제공·통지 확인자료와 위치 소유자 접근기록을 온라인 DB에서 즉시 삭제합니다. 위치 공유를 거부해도 가능한 범위에서 고정 승차 지점과 탑승 코드로 서비스를 이용할 수 있습니다.

열람·고지·정정·철회 요청은 운영자가 실제 담당자를 정하고 공개한 이메일/전화로 접수합니다. 연락처가 확정되지 않아 현재 문서는 시행 전 상태입니다.

## 5. 제공·위탁 및 위치정보 보호

위치 수집 동의만으로 상대에게 공개하지 않습니다. 선택한 별도 제공 동의와 수락된 운행 관계, 양쪽 동의·계정 자격을 확인한 뒤에만 위치를 보냅니다. 제공 상대와 통지·확인 방식은 [개인위치정보 제3자 제공 안내](location-sharing.md)에 따릅니다.

Google은 계정 인증을, Cloudflare는 Workers/D1 실행을 제공합니다. 현재 staging D1은 APAC 실행 지역이며 한국 내 저장을 보장하지 않습니다. Cloudflare 계약상 법인, 국외 처리 국가와 수탁자 상세는 서비스 개방 전에 확인해 게시해야 합니다. 위치정보 관련 법정 사업자 분류와 신고/등록 또는 예외 여부도 실제 운영 형태를 기준으로 확인해야 합니다.

위치정보 보호조치 기준이 적용되는 경우, 위치 취급대장은 6개월 이상, 위치 시스템 접근권한 부여·변경·말소 기록은 5년 이상 보관해야 합니다. 앱은 좌표 없는 제공·통지 기록과 위치 API 접근기록을 보관합니다. Cloudflare 운영자 접근권한 변경대장은 별도 외부 기록으로 운영해야 하며 아직 준비되지 않았으므로 원격 위치 공유를 열지 않습니다.
