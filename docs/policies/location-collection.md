## 1. 목적과 수집 방법

가천대학교 글로벌캠퍼스 이용자 간 수락된 운행에서, 지정 승차 지점에서 서로 만날 수 있도록 최신 위치를 표시합니다. 위치는 참고 정보이며 실제 탑승·출발·도착 판정이나 긴급 구조에 사용하지 않습니다. 개인위치정보를 처리하는 위치기반서비스사업으로 분류될 가능성이 있어 위치정보법 제9조 신고 또는 법정 예외 적용을 확인하기 전에는 실제 위치정보를 수집하지 않습니다. 가천대학교 운영의 경우 소상공인·1인 창조기업 절차를 당연히 적용하지 않습니다.

이용자가 위치 공유 화면에서 시작 버튼을 누르고, 별도의 위치 수집 동의와 브라우저 위치 권한을 허용할 때만 브라우저 Geolocation API가 반환한 위치를 전송합니다. 브라우저·운영체제가 GPS, Wi-Fi 등 어떤 원천으로 위치를 계산했는지는 앱이 항상 확인할 수 없습니다. 화면이 숨겨지면 위치 추적을 멈추며 백그라운드 추적, 항상 정확한 위치, 통신 성공을 보장하지 않습니다.

## 2. 수집 항목과 이용 범위

- 브라우저가 제공한 위도·경도와 정확도(미터)
- 위치 취득 시각과 서버 수신 시각
- 운행·탑승 요청 식별자, 갱신 sequence

이용자별 최신 위치 한 건만 저장하고 새 위치가 오면 덮어씁니다. 위치는 수락된 관계에서 상대를 찾는 용도로만 사용하고, 위치 이력을 만들거나 지도 경로를 추적하지 않습니다. 브라우저 권한을 거부하거나 동의를 철회하면 새 위치를 받지 않습니다.

## 3. 보유기간과 삭제

위치 좌표는 서버 수신 후 60초 동안만 API 응답 대상입니다. 60초가 지나면 API가 좌표를 반환하지 않습니다. 출발·취소·종료·중단, 관련 관계 해제, 위치 동의 철회 또는 탈퇴 때 최신 위치 행을 제거합니다. 위치 동의 철회·탈퇴 시에는 해당 사람의 위치에 관한 제공·통지 확인자료와 위치 소유자 접근기록도 온라인 DB에서 지체 없이 삭제합니다. 만료 행은 5분마다 실행되는 정리 작업으로 물리 삭제합니다. 정리 작업은 한 번에 제한된 행을 지우므로 오류나 적체가 있으면 물리 삭제가 늦어질 수 있습니다. 위치정보법 적용 시 동의 철회 후 관련 개인위치정보와 확인자료의 지체 없는 파기가 요구되므로, 실제 배포 전에 DB/백업까지 포함한 파기 시점을 법무·운영 검토하고 자동 점검해야 합니다.

삭제된 온라인 행과 별도로 staging D1 Time Travel에는 최대 7일의 복구 창이 있습니다. 이 기간 안에는 과거 시점의 좌표·제공자료가 복구될 수 있습니다. D1 백업에서 이 자료를 사용자별로 즉시 지울 수 있는지와 위치정보법·개인정보 보호법상 파기 요건을 충족하는지는 확인되지 않았습니다. 외부 삭제·철회 대조부는 복구 후 재노출 방지를 돕지만 백업 안 자료를 제거하지 않습니다. 백업 문제를 해소하고 복구 훈련을 마치기 전 위치 서비스와 일반 API를 열지 않습니다. 복구가 발생하면 API를 닫은 채 탈퇴·철회를 재적용해야 합니다. [운영 복구 절차](../operations/data-retention-and-restore.md)에 따릅니다.

## 4. 권리 행사와 대체 이용

위치 수집·제공 동의를 각각 거부하거나 언제든 철회할 수 있어야 합니다. 위치정보법상 일시 중지 요구도 거절할 수 없으므로, 수집·이용·제공을 각각 멈출 수 있는 기능을 제공해야 합니다. 현재 설정은 동의 철회는 제공하지만 법정 일시 중지 요청을 별도로 처리하는 기능과 연속 위치수집 시작 중지 UX가 완전하지 않아 이를 보완하기 전 시행할 수 없습니다. 철회 시 새 업로드·상대 조회를 차단하고 최신 좌표, 해당 사용자의 확인자료와 위치 소유자 접근기록을 온라인 DB에서 지체 없이 삭제합니다. 위치 공유를 거부해도 가능한 범위에서 고정 승차 지점과 탑승 코드로 서비스를 이용할 수 있습니다.

## 5. 제공·위탁 및 위치정보 보호

위치 수집 동의만으로 상대에게 공개하지 않습니다. 선택한 별도 제공 동의와 수락된 운행 관계, 양쪽 동의·계정 자격을 확인한 뒤에만 위치를 보냅니다. 제공 상대와 통지·확인 방식은 [개인위치정보 제3자 제공 안내](location-sharing.md)에 따릅니다.

Google은 계정 인증을, Cloudflare는 Workers/D1 실행을 제공합니다. 기록상 staging D1은 APAC이지만 한국 내 저장 보장이 아닙니다. D1 공식 지원 jurisdiction은 EU·FedRAMP·미국뿐이며 생성 후 변경할 수 없습니다. 기존 D1은 조회 오류로 이번에 재확인하지 못했습니다. 계정 계약상 Cloudflare 법인, 실제 국외 처리 국가·하위 처리자·항목·보유기간·이전 근거는 확인이 필요합니다. 사용자의 MVP 결정으로 위치정보법 제9조 사업 분류·신고 검토를 보류했으나 신고 불필요 또는 예외를 확인한 것은 아닙니다.

지도 표시에는 NAVER Cloud Platform Web Dynamic Map을 선택했습니다. 지도를 열면 브라우저가 SDK와 타일을 직접 요청하므로 접속 IP, Client ID, 출처와 요청 지도 영역이 제공자에게 전달될 수 있습니다. 앱은 지오코딩·경로 API를 쓰지 않고 위치 마커는 브라우저에서 표시하지만, SDK/타일 요청 항목과 처리 국가는 실제 network trace 및 Maps 서비스 약관에서 확인해야 합니다. NCP의 일반 글로벌 리전 해외 보관 안내만으로 Maps API 처리 국가를 추정하지 않습니다. [Maps 이용 시 데이터 보관·위탁 약관 안내](https://guide.ncloud-docs.com/docs/application-maps-procedure)

위치정보 보호조치 기준이 적용되면 위치정보관리책임자 지정, 단계별 최소 권한, 위치정보 처리·제공사실 자동 기록, 취급대장 최소 6개월 보관, 시스템 권한 부여·변경·말소 기록 최소 5년 보관과 연 1회 이상 자체점검이 필요합니다. 법정 확인자료는 구분해 기록해야 합니다. 수집사실 확인자료에는 수집요청인·수집일시·수집방법이, 이용·제공사실 확인자료에는 제공받는 자·취득경로·이용·제공일시·방법이 포함됩니다(위치 좌표 자체는 확인자료에 넣지 않음). 현재 DB에는 계정·캡처/수신 시각과 제공 수신자·목적·시각 일부가 있으나, 수집방법·취득경로·제공방법이 법정 수준으로 자동 기록되는지는 확인하지 않았습니다. 특히 브라우저 Geolocation API만으로 기기의 실제 측위 원천을 확인할 수 없습니다. Cloudflare 운영 권한도 별도 보호 대장으로 남겨야 하는데 실제 대장은 아직 없으므로 원격 위치 공유를 열지 않습니다.
