# 개인위치정보 수집·이용 안내

> **검토용 초안 · 위치 기능에 대한 동의 수집/원격 설정에 사용 금지**
> 위치정보법 적용 여부, 운영자 정보, 위치정보 관련 기록의 보유기간과 제3자 제공 통지 절차를 확정해야 합니다. 앱은 현재 위치 공유 시 매회 제3자 제공 통지·이용제공사실 확인자료 기록 기능이 없어 시행할 수 없습니다.

- 문서 버전: 초안 2026-10-28
- 시행일: [승인 후 입력]
- 위치기반서비스 운영자: [상호/성명, 주소, 전화번호, 기타 연락처 입력]
- 위치정보 담당자: [성명/부서, 전화번호, 이메일 입력]

## 1. 수집·이용 목적과 기능

Campus Ride는 가천대학교 글로벌캠퍼스 주변의 수락된 운행에서 운전자와 승객이 지정 승차 지점에서 서로 만날 수 있도록 현재 위치를 취득하고 표시합니다. 위치는 만남을 돕는 참고 정보이며 운행·탑승·도착 여부를 판정하거나 긴급 구조에 사용하는 기능이 아닙니다.

## 2. 수집 항목·방법·시점

| 항목 | 내용 |
| --- | --- |
| 개인위치정보 | GPS 등 브라우저가 제공한 위도·경도, 위치 정확도(미터) |
| 관련 정보 | 위치 취득 시각, 서버 수신 시각, 운행·탑승 요청 식별 정보 |
| 수집 방법 | 이용자가 수락된 운행 화면에서 위치 공유를 시작하고 브라우저 권한을 허용하면 브라우저 Geolocation 기능을 통해 전송 |
| 수집 시점 | 위치 공유 시작 후 화면이 보이는 동안, 브라우저가 새 위치를 제공하고 서버 업로드 간격 조건을 만족할 때. 브라우저 화면이 숨겨지면 새 위치 수집을 멈춤 |

브라우저·기기의 위치 설정이 꺼져 있거나 권한을 거부하면 수집하지 않습니다. 위치 오차와 갱신 지연이 있을 수 있으며, 백그라운드 추적이나 상시 정확한 위치를 보장하지 않습니다.

## 3. 보유 목적·기간 및 파기

현재 서버는 이용자별 최신 좌표 한 건을 저장하고 다음 위치가 도착하면 덮어씁니다. 서버 수신 시각으로 60초가 지나면 API에서 반환하지 않으며, 만료 행은 5분 간격 정리 작업으로 삭제될 수 있습니다. 운행의 출발·취소·종료·중단, 관계 정리 또는 위치 동의 철회 때 현재 좌표를 삭제합니다. 백업/Time Travel에 남을 수 있는 기간과 복구 뒤 재삭제 절차는 확정되지 않았습니다.

위치정보 사업자 등에 해당하면 수집·이용·제공사실과 이용자에게 고지한 사실을 확인할 취급대장을 자동 기록해야 하며, 현행 「위치정보의 관리적·기술적 보호조치 기준」은 취급대장을 최소 6개월 이상 보관하도록 정합니다. 현재 서비스에는 이 취급대장 기능이 없습니다. 위치정보 자체의 목적 달성 후 파기, 법정 확인자료의 6개월 보관, 백업의 처리기간을 구분해 [운영자 해당 여부와 운영 절차를 확정]해야 합니다. **60초 TTL은 위치정보법상 확인자료 또는 백업의 보유기간을 뜻하지 않습니다.**

## 4. 이용자 권리와 거부·철회

이용자는 위치 수집·이용 동의를 거부하거나 서비스 설정에서 언제든지 철회할 수 있습니다. 철회 후 새 위치 업로드와 위치 조회를 중단하고 현재 저장된 좌표를 삭제합니다. 동의를 거부해도 위치 공유를 제외한 서비스 이용은 가능한 범위에서 지정 승차 지점과 탑승 코드로 계속할 수 있습니다.

위치정보 수집·이용·제공 동의의 일부 또는 전부 철회, 열람·고지·정정 요청은 [담당자와 행사 방법 입력]으로 할 수 있습니다. 본인 확인, 접수·처리 방법 및 처리 기한은 [운영 절차 확정 필요]입니다.

## 5. 제3자 제공

위치 수집에 동의했다는 사실만으로 다른 이용자에게 위치를 공개하지 않습니다. 별도의 위치 공유 동의를 한 뒤, 수락 또는 탑승된 운행의 상대에게 제공되는 범위와 통지 방식은 [위치 공유 안내](location-sharing.md)에 따릅니다. 위치정보법상 위치기반서비스사업자 해당 여부와 필요한 신고·등록 여부는 [법률 검토 후 입력]합니다.

## 6. 개인정보 처리 위탁 및 안전조치

서버·데이터베이스 제공자: Cloudflare [계약상 법인명, 처리 지역, 재수탁자 및 국외 이전 정보 확인 필요]. 현재 staging D1의 실행 지역은 APAC이며 국내 저장을 보장하지 않습니다. 위치에 대한 운영자·수탁자의 기술적 접근 범위와 접근 기록·백업 관리는 [운영 통제 확정 필요]입니다.

### 작성 근거
