## 2. 수집 방법과 선택권

로그인은 Google OpenID Connect(`openid email profile`)를 사용합니다. 프로필·차량·운행·요청·신고 정보는 화면/API에서 입력받습니다. 계정·프로필·운행 처리는 서비스 제공 계약 이행에 필요한 범위로 제한합니다. 신고·보안기록 처리는 안전·권리 보호를 위한 정당한 이익을 근거로 삼을 수 있으나, 실제 운영주체가 필요성·정보주체 권리와의 비교형량을 문서화해야 합니다. 위치 수집·이용·제공에는 위치정보법상 사전 동의와 적용 가능한 개인정보 보호법상 처리 근거가 확인되어야 하며, 처리방침 확인이나 브라우저 권한만으로 법정 동의를 대신하지 않습니다. 위치는 이용자가 수락된 운행 화면에서 공유를 시작할 때 foreground에서만 받습니다. 거부·철회해도 지정 승차 지점과 탑승 코드 기능은 가능한 범위에서 이용할 수 있습니다.

사용자는 대학생 대상 MVP에는 만 14세 미만이 없다고 판단하여 별도 생년월일 수집과 보호자 동의 흐름을 MVP 범위에서 제외했습니다. Google OIDC의 `gachon.ac.kr` 도메인과 Workspace `hd` 확인은 연령 증명이 아니며, 서비스는 연령을 수집·검증하지 않습니다. 따라서 이 결정은 기술적으로 만 14세 미만이 배제됐다는 검증 결과가 아니라 제품 대상에 대한 사용자 가정입니다. 실제 만 14세 미만 이용이 확인되면 해당 위치 처리를 중지하고 법정대리인 동의·확인 절차를 마련해야 합니다.

개인정보 보호법 제28조의8은 국외 제공·처리위탁·보관에 법정 근거를 요구합니다. 계약 이행에 필요한 국외 처리위탁·보관 근거를 사용할 경우에도 이전 항목·국가·시기·방법·수령자 연락처·목적·기간·거부 방법과 효과를 이용자에게 알려야 합니다. Google·Cloudflare·NAVER의 공개 문서와 제품별 처리 조건은 서로 다르므로 한 제공자의 일반 처리방침을 다른 API에 대입하지 않았습니다. 현 시점에 실제 수령 국가와 서비스별 하위 처리자를 특정하지 못했으므로 이 표는 최종 국외이전 고지를 충족하지 않으며 실제 계정/약관과 이전 근거 확인 전 게시·동의에 사용할 수 없습니다.

## 5. 탈퇴·파기·백업

이용자는 계정 설정에서 최근 재인증 후 탈퇴할 수 있습니다. 탈퇴 이벤트는 계정의 Google 식별값을 대체하고, 세션·학생확인 자료·멱등 기록·최신 위치·차단 관계와 본인 위치의 제공·통지 확인자료를 삭제하며 동의를 철회하고 진행 중 운행/요청을 종료합니다. 과거 운행·요청·신고·동의·감사, 타인의 위치를 조회한 보안 접근기록 및 이용자가 수신자로 포함된 위치 제공 확인자료는 위 기간 동안 남을 수 있어 탈퇴 즉시 모든 연결 기록이 사라지는 것은 아닙니다.

현재 staging의 Cloudflare Workers Free D1 Time Travel 복구 창은 최대 7일입니다. Cloudflare D1에서 한국 전용 jurisdiction은 지원되지 않습니다. 공식 D1 문서상 생성 시 설정 가능한 jurisdiction은 EU, FedRAMP, 미국이며 기존 DB에는 나중에 추가할 수 없습니다. `APAC` location hint는 선호 위치를 보장하지 않으며 한국 내 저장 보장도 아닙니다. 직전 staging 기록은 APAC이나 이번 읽기 전용 재조회는 Cloudflare API 인증 오류로 확인하지 못했습니다. 온라인 행을 삭제해도 Time Travel의 이전 상태는 사용자별로 지울 수 없고 전체 복원 시 삭제·철회 전 정보가 되살아날 수 있습니다. 외부 대조부는 복원 뒤 접근 차단을 돕지만 백업 자체의 법적 파기 의무를 충족한다고 단정할 수 없습니다. 파기·복구 적합성 확인 전 위치 기능과 일반 API는 닫습니다. [운영 복구 절차](../operations/data-retention-and-restore.md)를 따릅니다.

## 7. 쿠키·자동 수집 및 안전조치

로그인 세션은 `HttpOnly`, `Secure`, `SameSite=Lax` 속성의 서비스 쿠키로 전달합니다. 로그인 쿠키를 차단하면 인증이 작동하지 않을 수 있습니다. 광고 목적 추적 쿠키는 사용하지 않는 것으로 설계했으나 지도 SDK·Cloudflare 등 외부 요청이 브라우저 저장소나 접속정보를 처리하는지 실제 환경에서 확인해야 합니다. 서비스는 요청·좌표·OAuth 값을 애플리케이션 로그에 남기지 않도록 설정했으나, Cloudflare 계정 로그의 항목·보유기간·접근 국가는 계정 및 계약 확인 전 미확정입니다.

구현된 범위에서 opaque session 토큰 해시 저장, HTTPS 쿠키, 리소스별 권한 확인, 민감 응답 `no-store`, 위치 갱신 제한과 최소화된 운영 로그를 적용합니다. 접근권한·취급자 교육·위치정보관리책임자 지정, Cloudflare 권한 변경 외부대장, 백업 복구와 삭제 재적용 점검은 아직 운영되지 않습니다.
