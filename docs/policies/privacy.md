# 개인정보 처리방침

> **확정안 v1.0 · 시행 보류.** 보유기간과 처리 방식은 이 문서를 기준으로 정했으며, 실제 서비스에 적용하기 전 운영자 실명/상호, 주소, 대표 연락처와 개인정보 보호책임자 연락처를 확인·게시해야 한다. 위치정보 서비스의 신고·등록/예외 해당 여부와 위탁·국외이전 세부 고지도 확인 전까지 일반 API를 열지 않는다.

- 정책 결정 기준일: 2026-10-28
- 시행일: 서비스 일반 API를 열기 전에 표시되는 날짜
- 개인정보처리자: 운영 주체 확정 필요
- 개인정보 보호책임자 또는 문의 담당자: 운영자가 지정할 실제 담당자와 연락처 확정 필요

## 1. 처리 목적·항목·기간

| 목적과 정보 | 보유기간 및 파기 |
| --- | --- |
| Google 로그인: Google ID token을 검증하고 `sub`, 확인된 이메일, Google 표시 이름, Workspace `hd`를 확인합니다. 계정 식별을 위해 `sub`와 이메일을 저장하고, 표시 이름은 사용자가 바꿀 수 있는 최초 닉네임 후보로 씁니다. | 계정 이용 중. 탈퇴 접수 시 `sub`·이메일은 대체값으로 바꾸고 닉네임을 가명화합니다. 탈퇴 표식 행은 원칙적으로 1년 후 삭제하며, 남은 운행·신고 등 연결 자료가 먼저 정리되어야 합니다. |
| 계정·프로필·차량: 내부 UUID, 닉네임, 성별 선택, 학과 후보·확인 상태, 가천대학교/글로벌캠퍼스 값, 차량 모델·색상·식별정보·정원·검토 상태 | 이용 중. 탈퇴 시 직접 식별 프로필과 차량 식별정보를 즉시 대체·초기화하고 진행 중 활동을 종료합니다. 계정 연결 표식은 위 기간 및 연결 기록 정리 조건을 따릅니다. 별도 학적 자료는 조회하지 않습니다. |
| 운행·탑승 요청: 출발·목적지, 시간, 좌석, 매칭 조건, 상태 전이, 운행·요청 UUID | 활성 중 보유. 종료 후 180일에 삭제합니다. 연결된 신고가 열려 있으면 신고가 종결된 뒤 1년까지 함께 보관합니다. |
| 신고·처리 이벤트: 신고 유형·설명, 관련 운행/요청, 처리 상태와 조치 이벤트 | 신고가 종결될 때까지 보유하고 종결 후 1년 뒤 삭제합니다. 미종결 신고는 종결 전까지 보관합니다. |
| 선택형 최신 위치: 위도·경도, 정확도, 취득·수신 시각, 운행/요청 연결값 | 계정/관계/동의가 유효한 동안 최신 1건만 저장합니다. 수신 후 60초부터 API에서 반환하지 않습니다. 관계 종료, 위치 동의 철회, 탈퇴 때 온라인 행을 삭제합니다. 만료 행은 5분 Cron 정리 작업으로 삭제하며 작업 지연·100행 처리 한도 때문에 물리 삭제가 늦어질 수 있습니다. |
| 위치 제공 및 통지 확인자료: 위치 소유자·수신자 UUID, 수신자 닉네임/역할 스냅샷, 운행·요청, sequence, 요청·제공 시각, 목적, 사전 알림·제공 후 확인 시각 | 좌표 없이 최대 6개월 보관합니다. 위치 소유자가 위치 관련 동의를 철회하거나 탈퇴하면 그 사람의 위치에 관한 제공·통지 자료를 즉시 온라인 DB에서 삭제합니다. 화면에는 보유 중인 최근 20건을 표시합니다. |
| 위치 API 접근기록: 행위자·위치 소유자 UUID, 업로드/본인조회/상대조회 구분, 운행·요청 UUID, 시각 | 좌표 없이 1년 보관합니다. 위치 소유자가 위치 관련 동의를 철회하거나 탈퇴하면 그 사람의 위치에 관한 접근기록을 온라인 DB에서 즉시 삭제합니다. |
| 동의 이력: 동의 종류·문서 버전·동의/철회 시각 | 동의가 유효한 동안과 철회 후 1년까지 보관한 뒤 삭제합니다. |
| 보안·운영 감사기록 | 원칙적으로 1년 보관합니다. 유효한 계정 제한, 신고, 차단 또는 운영 설정을 설명하는 데 필요한 최신 연결 이벤트는 해당 상태가 끝나거나 교체될 때까지 보관할 수 있습니다. |
| 위치정보 시스템 접근권한 부여·변경·말소 이력 | 위치정보 보호조치 기준 적용 대상인 경우 5년 이상 보관합니다. Cloudflare 계정 권한의 별도 접근통제대장을 운영자가 안전한 외부 기록소에 유지해야 합니다. 이 대장은 아직 준비되지 않아 원격 위치 공유는 열지 않습니다. |

법령에 따라 별도 보존이 필요한 경우 해당 정보와 법적 근거를 분리해 보관합니다. 이 서비스는 현재 별도의 법정 보존 예외를 설정하지 않았습니다. 파기 작업은 5분마다 실행되고 한 번에 제한된 행을 처리하므로, 정리 실패·적체가 있으면 온라인 DB의 실제 삭제는 늦어질 수 있습니다. 만료 좌표는 삭제 전에도 API가 반환하지 않습니다.

## 2. 수집 방법과 선택권

로그인은 Google OpenID Connect(`openid email profile`)를 사용합니다. 프로필·차량·운행·요청·신고 정보는 화면/API에서 입력받습니다. 위치는 이용자가 수락된 운행 화면에서 공유를 시작하고 브라우저 권한을 허용할 때만 foreground에서 받습니다. 위치 수집과 상대 제공은 서로 다른 선택 동의이며, 거부·철회해도 지정 승차 지점과 탑승 코드 기능은 가능한 범위에서 이용할 수 있습니다.

## 3. 제3자 제공

위치 외 정보는 운행 연결에 필요한 범위에서 상대 이용자에게 표시될 수 있습니다. 위치는 별도의 제공 동의, 수락된 운행 관계, 양쪽의 유효한 위치 동의, 계정 자격 및 차단 상태를 모두 확인한 경우에만 지정된 운행 상대에게 보냅니다. 제공받는 범위와 통지 절차는 [개인위치정보 제3자 제공 안내](location-sharing.md)에 설명합니다. 가천대학교에 가입·운행·위치 정보를 제공하지 않으며, 서비스가 학교의 공식 서비스·제휴 서비스라고 표시하지 않습니다.

## 4. 처리 위탁·서비스 제공자·국외 처리

| 제공자 | 업무 | 현재 확인된 사실과 게시 전 확인 사항 |
| --- | --- | --- |
| Google LLC | Google 계정 인증 | 로그인에 필요한 scope만 요청하며 Google API refresh token은 저장하지 않습니다. |
| Cloudflare | Workers 실행 및 D1 데이터베이스 | staging D1은 `production` backend, APAC 실행 지역이며 국내 저장을 보장하지 않습니다. 계약상 법인, 처리·이전 국가, 수탁자·재수탁자와 이전의 법적 근거를 계약/계정 설정에서 확인해 게시해야 합니다. |

## 5. 탈퇴·파기·백업

이용자는 계정 설정에서 최근 재인증 후 탈퇴할 수 있습니다. 탈퇴 이벤트는 계정의 Google 식별값을 대체하고, 세션·학생확인 자료·멱등 기록·최신 위치·차단 관계와 본인 위치의 제공·통지 확인자료를 삭제하며 동의를 철회하고 진행 중 운행/요청을 종료합니다. 과거 운행·요청·신고·동의·감사, 타인의 위치를 조회한 보안 접근기록 및 이용자가 수신자로 포함된 위치 제공 확인자료는 위 기간 동안 남을 수 있어 탈퇴 즉시 모든 연결 기록이 사라지는 것은 아닙니다.

현재 staging의 Cloudflare Workers Free D1 Time Travel 복구 창은 최대 7일입니다. 온라인 D1에서 위치자료를 삭제해도 복구 창의 과거 상태는 즉시 개별 삭제되지 않으며, 전체 DB 복구 때 삭제·철회 전 자료가 되살아날 수 있습니다. D1 밖의 최소 삭제·철회 대조부로 복구 뒤 재적용하도록 절차를 정했지만, 백업 안 위치자료의 보존을 법적으로 허용할 수 있는지와 삭제를 어떻게 충족할지는 확인되지 않았습니다. 이 점과 복구 대조부가 해결되기 전 위치 기능과 일반 API를 열지 않습니다. [운영 복구 절차](../operations/data-retention-and-restore.md)를 따릅니다.

## 6. 권리 행사·문의

정보주체는 개인정보 열람, 정정·삭제, 처리정지, 동의 철회를 요청할 수 있습니다. 계정 탈퇴와 위치 동의 철회는 설정 화면에서 할 수 있습니다. 그 밖의 요청은 아래 실제 운영자/담당자에게 접수할 수 있게 게시해야 합니다. 담당자의 실명/상호와 연락처는 사용자 확인이 필요하므로 현재 공란이며, 확정 전에는 이 문서를 효력 있는 고지로 사용하지 않습니다.

- 운영 주체와 주소: 실제 값 확인 필요
- 개인정보 보호책임자/담당자: 실제 지정 필요
- 공개 이메일·전화번호: 실제 문의처 확인 필요
- 위치정보 열람·통지·정정 요청 접수 방법: 실제 문의처 확정 후 서비스에 게시. 공개 연락처가 없어 현재는 접수 경로가 마련되지 않았습니다.
