## 2. 수집 방법과 선택권

로그인은 Google OpenID Connect(`openid email profile`)를 사용합니다. 프로필·차량·운행·요청·신고 정보는 화면/API에서 입력받습니다. 계정·프로필·운행 처리는 서비스 제공에 필요한 범위로 제한해야 하며 실제 운영주체가 처리 근거를 확정해야 합니다. 현재 브라우저 위치 API를 호출하거나 이용자 단말 좌표를 수집하지 않습니다. 이용자는 등록 노선의 고정 승차 지점을 선택하고 현장에서 기다립니다. 이 선택 기록의 개인정보·위치정보 해당 여부 및 처리 근거는 미확정입니다.

사용자는 대학생 대상 MVP에는 만 14세 미만이 없다고 판단하여 별도 생년월일 수집과 보호자 동의 흐름을 MVP 범위에서 제외했습니다. Google OIDC의 `gachon.ac.kr` 도메인과 Workspace `hd` 확인은 연령 증명이 아니며, 서비스는 연령을 수집·검증하지 않습니다. 따라서 이 결정은 기술적으로 만 14세 미만이 배제됐다는 검증 결과가 아니라 제품 대상에 대한 사용자 가정입니다. 실제 만 14세 미만 이용이 확인되면 해당 위치 처리를 중지하고 법정대리인 동의·확인 절차를 마련해야 합니다.

## 5. 탈퇴·파기·백업

이용자는 계정 설정에서 최근 재인증 후 탈퇴할 수 있습니다. 탈퇴 이벤트는 계정의 Google 식별값을 대체하고, 세션·학생확인 자료·멱등 기록·과거 위치 관련 온라인 행·차단 관계를 정리하고 동의를 철회하며 진행 중 운행/요청을 종료합니다. 과거 운행·요청·신고·동의·감사 기록과 구형 위치 기능의 일부 데이터는 별도 보유·삭제 검토가 끝날 때까지 남아 있을 수 있습니다. D1 복구 사본에 삭제 전 정보가 남는지, 복구 후 재적용이 필요한지는 확인 전입니다.

현재 staging의 Cloudflare Workers Free D1 Time Travel 복구 창은 최대 7일입니다. Cloudflare D1에서 한국 전용 jurisdiction은 지원되지 않습니다. 공식 D1 문서상 생성 시 설정 가능한 jurisdiction은 EU, FedRAMP, 미국이며 기존 DB에는 나중에 추가할 수 없습니다. `APAC` location hint는 선호 위치를 보장하지 않으며 한국 내 저장 보장도 아닙니다. 직전 staging 기록은 APAC이나 이번 읽기 전용 재조회는 Cloudflare API 인증 오류로 확인하지 못했습니다. 온라인 행을 삭제해도 Time Travel의 이전 상태는 사용자별로 지울 수 없고 전체 복원 시 삭제·철회 전 정보가 되살아날 수 있습니다. 외부 대조부는 복원 뒤 접근 차단을 돕지만 백업 자체의 법적 파기 의무를 충족한다고 단정할 수 없습니다. 파기·복구 적합성 확인 전 위치 기능과 일반 API는 닫습니다. [운영 복구 절차](../operations/data-retention-and-restore.md)를 따릅니다.

## 7. 쿠키·자동 수집 및 안전조치
